# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Supabase Factory, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email the maintainers directly or use GitHub's private vulnerability reporting feature:

1. Go to the repository's **Security** tab
2. Click **Report a vulnerability**
3. Provide a detailed description of the issue

## What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Fix & disclosure**: Coordinated with the reporter

## Scope

This policy covers the Supabase Factory application itself. For vulnerabilities in generated output (SQL, edge functions), please note that the generated code is a starting point and should be reviewed before production use.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

Thank you for helping keep Supabase Factory and its users safe.
